# 视觉与音调数据来源

## 日本三维场景

- 日本边界轮廓来自 Natural Earth 50m Admin 0 Countries，转换为 `public/assets/japan/land.json`。
- 地表纹理来自 NASA Earth Observatory Blue Marble Next Generation topography，裁切为 `public/assets/japan/satellite.webp`。
- 场景仅用于网站内的虚构交互视觉，不表示真实武器、目标或效果模拟。

生成命令：

```bash
node scripts/build_japan_assets.mjs <natural-earth-geojson> <nasa-world-jpg>
```

## 东京式音调

词条的音调来自 UniDic 2.1.2（通过 `unidic-lite` 提取 `aType`）。脚本只接受词形、读音、词典条目完全匹配的结果；没有严格匹配的词显示“音调待核对”，不会猜测。覆盖率和未匹配清单见 `docs/data/pitch-accent-coverage.json`。

生成命令：

```bash
/tmp/tensei-pitch-modern/bin/python scripts/build_pitch_accents.py
```
