## 三、单词接口标准

词汇请求体：

```json
{
  "bank_id": "词库UUID",
  "words": [
    {
      "surface": "話す",
      "reading": "はなす",
      "meaning_cn": "说话",
      "pos": "动词",
      "verb_type": "godan",
      "adj_type": null,
      "segments": [
        { "text": "話", "kana": "はな" },
        { "text": "す" }
      ],
      "example": {
        "segments": [
          { "text": "毎日、友達と" },
          { "text": "話", "kana": "はな" },
          { "text": "します。" }
        ],
        "cn": "我每天和朋友聊天。"
      }
    }
  ]
}
```

必填字段：

- `surface`：词典形原形
- `reading`：完整纯假名读音
- `meaning_cn`：准确中文释义

结构化词性要求：

- 动词必须填写 `verb_type`：`godan`、`ichidan`、`kahen`、`sahen` 之一
- い形容词必须填写 `adj_type: "i"`
- な形容词必须填写 `adj_type: "na"`
- 名词、副词等不可变位词的两个结构化字段均为 `null`
- `pos` 不能替代 `verb_type` / `adj_type`

### 3.1 サ変硬性规则

只要词条标为 `sahen`：

- `surface` 必须是完整 `〇〇する`
- `reading` 必须是完整 `〇〇する`
- 裸名词如 `案内`、`挨拶`、`哀願` 不能直接标成 `sahen`
- 如果原始资料只给出裸词干，必须补成 `案内する` / `あんないする` 后再提交
- `擦る`、`刷る` 等虽然读音包含「する」，但不是サ変，不能误判为 `sahen`

### 3.2 单词例句硬性规则

禁止以下内容：

```text
これは“某词”这个词。
これは……という言葉です。
这个句子使用“某词”。
歌词意境：原句。
```

例句必须：

- 是自然、真实的日语句子，而不是词典元话语或占位模板
- 体现该词真实词义和词性
- 中文翻译准确、通顺，与日语语义对应
- 例句场景不能脱离词义
- `segments` 中的 `text` 拼接后必须等于完整日语例句
- 含汉字的分段才填写对应 `kana`
- 不得把整句错误地标成某个单词的读音

示例：

```json
{
  "surface": "愛国",
  "reading": "あいこく",
  "meaning_cn": "爱国",
  "pos": "名词",
  "verb_type": null,
  "adj_type": null,
  "example": {
    "segments": [
      { "text": "彼は" },
      { "text": "愛国", "kana": "あいこく" },
      { "text": "心の強い人です。" }
    ],
    "cn": "他是一个爱国心很强的人。"
  }
}
```

## 四、句型/语法接口标准

旧版字段不足以支撑教程化学习。推荐使用扩展结构：

```json
{
  "pattern": "Vてもいいです",
  "reading": null,
  "meaning_cn": "可以做……，表示许可",
  "lesson": "新标日初级上·第15课",
  "connection": "动词て形＋もいいです",
  "usage": "用于表示许可；疑问形式 Vてもいいですか 用于请求许可。",
  "notes": "与 Vてはいけません 相反；前者表示允许，后者表示禁止。",
  "level": "N5",
  "example": {
    "segments": [
      { "text": "ここで写真を撮ってもいいですか。" }
    ],
    "cn": "可以在这里拍照吗？"
  },
  "examples": [
    {
      "segments": [
        { "text": "ここで写真を撮ってもいいですか。" }
      ],
      "cn": "可以在这里拍照吗？"
    }
  ]
}
```

字段要求：

- `pattern`：唯一的句型文本
- `meaning_cn`：明确说明含义和功能
- `lesson`：教材来源、课次或主题
- `connection`：明确接续方式
- `usage`：中文教程式讲解，说明使用场景和语气
- `notes`：限制、易错点、近义句型区别
- `example`：至少一个自然例句
- `examples`：建议放多个经过校对的例句
- `reading`：没有可靠读音时可以为 `null`，不能臆造

### 4.1 句型例句硬性规则

禁止：

```text
この文では「〜某句型」を使います。
这个句子使用“〜某句型”。
按句型接续规则使用。
```

每个语法点必须有：

1. 真实的日语使用情境
2. 与该语法点语义匹配的中文翻译
3. 明确接续说明
4. 中文教程说明
5. 至少一个易错点或语用限制（如果确实存在）
